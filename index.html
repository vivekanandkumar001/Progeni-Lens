02 / PIPELINE

What is actually running

01

Letterbox preprocessing

Frames are resized to 640 × 640 with proportional padding, then converted to CHW float tensors.

02

ONNX inference

The official YOLOv5s v7 graph runs through ONNX Runtime Web with the WASM execution provider.

03

Decode + NMS

Raw anchors are decoded back to source coordinates, scored, then filtered with per-class IoU suppression.

04

Mode alerts

Detections are matched against the selected mode’s supported COCO classes to raise an on-screen alert.
